# إنجاز — بوابة خدمات عامة (واجهة تجريبية)

واجهة عربية RTL متجاوبة باستخدام React + TypeScript + Vite + Tailwind CSS + Lucide.

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. فك ضغط المشروع.
3. من مجلد المشروع نفّذ:
   ```bash
   npm install
   npm run dev
   ```
4. لبناء نسخة الإنتاج:
   ```bash
   npm run build
   npm run preview
   ```

## الصفحات
- الرئيسية `/`
- جميع الخدمات `/services`
- تفاصيل الخدمة `/services/:id`
- طلب جديد `/request`
- تتبع الطلبات التجريبية `/track`
- من نحن `/about`
- تواصل معنا `/contact`
- سياسة الخصوصية `/privacy`
- الشروط والأحكام `/terms`

## مهم قبل الإطلاق
- الاسم والشعار وبيانات التواصل تجريبية.
- نموذج الطلب يحفظ البيانات في `localStorage` على نفس المتصفح فقط، ولا يرسلها لخادم.
- التتبع محلي وتجريبي، وليس مرتبطاً بمنصة حكومية.
- روابط واتساب تحتاج إلى رقم المكتب بصيغة دولية.
- راجع سياسة الخصوصية والشروط قانونياً، وأضف backend آمن وصلاحيات وصول وحماية للملفات قبل جمع بيانات حقيقية.
- لا تعرض خدمة على أنها متاحة فعلياً إلا بعد التحقق من صلاحية المكتب لتقديمها.
